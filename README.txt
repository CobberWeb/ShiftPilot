ShiftPilot v9 — Mobile Driver Dashboard

Major UI overhaul
- Designed around a phone mounted in a car.
- Main HOME dashboard now shows the important information without opening tabs:
  - live shift status and seconds timer
  - current shift earnings
  - $/hour
  - order count
  - $/km
  - total / on-order / off-order distance
  - estimated shift fuel cost
  - saved Queensland Government fuel price
  - weekly earnings / target
  - weekly hours / target
  - today's planned work block
- Large touch targets and high-contrast glanceable numbers.
- Bottom navigation reduced to HOME / ORDER / EXPENSES / MORE.
- Quick actions from Home for Order Checker, Expense entry and Shift History.
- Shift History moved under More.
- Weekly plan/settings/tax/fuel detail remain available without crowding the main dashboard.
- Fuel card on Home shows the government price after it has been loaded.
- Update Price takes you directly to the fuel-price controls.
- Existing Queensland Government Netlify function remains included.
- Existing expense, tax, order, shift, odometer, and delete-shift features remain.

Safety design
- The mounted-phone Home view is intended primarily for glanceable information.
- Data entry remains on dedicated screens for use while safely stopped.
